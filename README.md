# DROPGENIUS AI 🚀
### Discover Products. Calculate Profits. Build Smarter.

DROPGENIUS AI is an AI-powered dropshipping platform designed to simplify product research, profit analysis, and product content creation through an intuitive desktop application.

## ✨ Features

- 🔎 **Product Finder** — Explore potential products for your dropshipping business.
- 💰 **Profit Calculator** — Calculate costs, selling prices, and potential profit.
- 🧠 **AI Product Studio** — Generate AI-assisted product content.
- 🖥️ **Desktop Application** — Built with Electron for a desktop experience.
- ⚡ **Backend Integration** — Powered by a Node.js and Express backend.
- 🤖 **AI Integration** — Optional OpenAI API integration.

## 🛠️ Tech Stack

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/cynox321-oss/DROPGENIUS-AI.git
```

### 2. Enter the project directory

```bash
cd DROPGENIUS-AI
```

### 3. Install dependencies

```bash
npm install
```

Install backend dependencies separately if the backend has its own `package.json`:

```bash
cd backend
npm install
```

### 4. Configure AI

If using OpenAI integration, configure your API key in a local environment file. Never publish API keys or credentials.

### 5. Run

Start the backend using its configured command, then launch the Electron application using the start script defined in the root `package.json`.

## 🔐 Security

- Never commit `.env` files.
- Never expose API keys or private credentials.
- Keep dependencies and configuration files secure.
